# Create and Manage Your Teacher Profile

Your teacher profile helps students learn about you and register for your
classes. You can add your profile information, choose a profile picture,
control whether the profile is public, and share its public link.

## Open your teacher profile

1. Sign in to Yarpad as a teacher.
2. Open the menu.
3. Expand **Settings** and select **Profile**.

<!-- Screenshot placeholder: The teacher menu with Settings expanded and Profile selected. -->

The **Teacher profile** page opens. If you already have a profile, your saved
information appears in the form.

## Complete your profile

Enter the following required fields:

- **Display name** — the name students see on your profile.
- **Headline** — a short introduction or description of your teaching.
- **Bio** — more information about you and your teaching.

These fields cannot be empty. You can save your information as a draft before
making the profile public.

<!-- Screenshot placeholder: The Teacher profile form showing Display name, Headline, and Bio. -->

### Save your profile information

Select **Save** to store changes to your display name, headline, and bio.

Saving does not publish a draft or hidden profile. If the profile is already
published, changes saved to it remain publicly visible without republishing.

## Add or change your profile picture

Your profile picture must be a JPEG, PNG, or WEBP image no larger than 5 MB.

1. Select your profile picture or avatar on the Teacher profile page.
2. Choose an image from your device gallery.
3. Adjust the image in the square crop area.
4. Select **Upload**.

Yarpad uploads the cropped image and returns you to your profile when the
upload is complete. You can repeat these steps to change the picture.

<!-- Screenshot placeholder: The device gallery selection followed by the Upload your picture crop screen. -->

If the image cannot be uploaded, check that it is a JPEG, PNG, or WEBP file,
is no larger than 5 MB, and contains a non-empty image. Then select the avatar
again and try a different image.

## Publish or hide your profile

The action beside **Save** depends on your profile's current visibility.

- **Save and Publish** saves your profile information and publishes the
  profile. Students can then access the public profile.
- **Save and Hide** saves your profile information and hides the profile from
  public access.

Draft and Hidden profiles are not publicly accessible. To make a draft or
hidden profile public, complete the required fields and select **Save and
Publish**.

If a profile is already published, select **Save** when you only want to save
information changes. Those changes become publicly visible after saving. Use
**Save and Hide** when you want to save the changes and remove the profile
from public access.

<!-- Screenshot placeholder: A completed Teacher profile form showing the Save, Save and Publish, or Save and Hide actions. -->

## Preview and copy your public profile link

The first successful save creates your public profile link. After saving:

1. On the Teacher profile page, find the profile-link card.
2. Select the card to preview your profile.
3. Select the copy icon to copy the public profile link.

You can share the copied link with students. The public profile shows your
profile picture, display name, headline, and bio.

<!-- Screenshot placeholder: The generated public profile link card with the preview area and copy icon. -->

## Let students register through your profile

Publish your profile and share its public link with students. A student who
opens the public profile can select **Register for class** to begin student
registration with you.

<!-- Screenshot placeholder: The public teacher profile showing the Register for class button. -->

The **Register for class** action is available on the public profile when the
registration option is present.

## Complete the Teacher Profile onboarding step

If Yarpad asks you to complete onboarding:

1. Select **Start** on **Teacher Onboarding**.
2. On the **Teacher profile** step, select **Continue**.
3. Complete your display name, headline, and bio.
4. Save your profile, or select the available publish action.
5. Continue through the remaining onboarding steps.

The Teacher Profile step is followed by **Working hours** and **Teaching
policies**. Select **Finish** when you complete the onboarding sequence.

<!-- Screenshot placeholder: The Teacher Onboarding screen with the Teacher profile step and Continue button. -->

## Troubleshooting

### A required-field message appears

Check that **Display name**, **Headline**, and **Bio** each contain text.
Save again after completing all three fields.

### The image will not upload

Confirm that the selected file is a JPEG, PNG, or WEBP image and is no larger
than 5 MB. Select a non-empty image, crop it, and select **Upload** again.

### The public profile link is missing

Select **Save** after completing the required fields. The link is generated
after the first successful save. If it still does not appear, reload the
Teacher profile page and try saving again.

### The profile is not publicly visible

Check the profile action and status:

1. Complete all required fields.
2. Select **Save and Publish**.
3. Open the public profile link again.

Draft and Hidden profiles are not publicly accessible. If the profile was
already published, select **Save** to store current edits; those edits become
public after saving. If the link still does not work, confirm that you are
using the copied public profile link and contact support.
