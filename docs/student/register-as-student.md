# Register as a Student

To create a student account, start from your teacher's public Yarpad profile
or from a valid registration link provided by your teacher. Student
self-registration is associated with the teacher whose registration link you
use.

## Register for a class

1. Open your teacher's public profile or a valid registration link from your
   teacher.
2. Select **Register for class**.
3. On **Student account registration**, enter your **Full name**, **Email**,
   and **Password**.
4. Select **Register**.
5. After registration succeeds, sign in with the email address and password
   you registered.

Do not start student registration from a general registration page without a
teacher's registration link. That path is for creating a teacher account.

### Password requirements

Your password must contain:

- At least 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one supported special character: `! @ # $ & * ~`

## Activate your account

Your account is activated after you enter the code from the activation email.

1. Attempt to sign in with the email address and password you registered.
2. Open the email titled **Activate Your Account**.
3. Find the 9-digit activation code in the email.
4. Enter the code on the **Email Verification** page.
5. Select **Submit**.

After the code is accepted, Yarpad logs you in automatically.

## Your teacher association

Student registration automatically associates your account with the teacher
whose public profile or registration link you used. You do not need to enter
the teacher's details separately during registration.

## Troubleshooting

### The activation code is not accepted

Check that you entered the complete 9-digit code from the **Activate Your
Account** email. If the code is invalid, the page displays an activation-code
error.

### I did not receive an activation email

Attempt to sign in again with your registered email address and password. For
an inactive account, this sign-in attempt triggers another activation email.

### I cannot start student registration

Open the registration link provided by your teacher, or open the teacher's
public profile and select **Register for class**. A general registration page
without the teacher's registration link starts teacher registration instead.
